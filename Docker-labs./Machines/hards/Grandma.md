# Arquitectura de red

Para comenzar, se muestra cuál es la arquitectura de red definida para este laboratorio.

En este caso, la diferencia fundamental con laboratorios de menor dificultad esta en que cuenta con una serie de 4 máquinas conectadas entre sí, asignadas en 4 redes distintas.

Cada máquina está configurada como dual-homed, lo que significa que cada una pertenece a dos redes al mismo tiempo usando dos interfaces de red distintas. Además, ambas interfaces están habilitadas simultáneamente, lo que hace posible el movimiento lateral en este ejercicio.

Se aporta el siguiente esquema asignando además un nombre orientativo a las máquinas, para poder tener una referencia visual a lo largo de la guía y comprobar como progresa el ejercicio.
